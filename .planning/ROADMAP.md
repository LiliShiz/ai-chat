# Roadmap — AI Chat (v1)

4 фазы, каждая — feature-ветка и отдельный PR-able кусок работы.
Порядок выбран «снизу вверх»: сначала то, по чему нас оценивают в первую
очередь (ключ на сервере, стриминг, отмена), потом вкус.

### Phase 1: Прокси и стриминг
**Goal:** Сервер, который держит ключ у себя и ретранслирует SSE от OpenRouter
без буферизации, с пробросом отмены на апстрим.
**Mode:** mvp
**Requirements:** PROXY-01, PROXY-02, PROXY-03, PROXY-04, PROXY-05
**Success Criteria**:
1. `curl -N localhost:8787/api/chat` отдаёт чанки по мере генерации, а не одним куском
2. В `dist/` фронта и в DevTools Network нет строки ключа
3. Обрыв соединения клиентом закрывает запрос к OpenRouter (видно в логе сервера)
4. 429 и таймаут превращаются в SSE-событие `error` с кодом и человекочитаемым текстом

### Phase 2: Чат, отмена, края
**Goal:** Рабочий React-чат: отправка, потоковый рендер, «Стоп» без потери
текста, явные состояния всех четырёх аварий из ТЗ.
**Mode:** mvp
**Requirements:** CHAT-01…06, ERR-01…04
**Success Criteria**:
1. Ответ печатается по мере генерации; во время генерации виден индикатор
2. «Стоп» на середине оставляет частичный текст в истории, интерфейс живой
3. 429 / таймаут / обрыв сети дают три разных понятных состояния, не спиннер
4. После любой ошибки доступны «Повторить» и поле ввода
5. F5 не теряет историю (sessionStorage), «Очистить» стирает её

### Phase 3: Доступность и вкус
**Goal:** Клавиатура, семантика, адаптив, пустое состояние, тёмная тема,
markdown. И честно оформленный пушбек по `outline`.
**Mode:** mvp
**Requirements:** A11Y-01…05, UI-01…04
**Success Criteria**:
1. Полный сценарий (написать → отправить → остановить) проходится без мыши
2. Фокус виден всегда, при этом дефолтного браузерного `outline` нет
3. На 375px ничего не уезжает, лента скроллится, ввод доступен
4. До первого сообщения видно осмысленное пустое состояние, а не пустота
5. Ответы модели рендерятся как markdown, тема следует системной

### Phase 4: Сдача
**Goal:** Репозиторий, который приятно открыть: README с решениями и ИИ-логом,
LICENSE, история коммитов, смерженный PR.
**Mode:** mvp
**Requirements:** PROC-01…06
**Success Criteria**:
1. По README проект поднимается с нуля меньше чем за 5 минут
2. В README есть раздел с пушбеком по `outline` и обоснованием sessionStorage
3. ИИ-лог называет конкретные ошибки ИИ и как они были пойманы
4. В репозитории есть LICENSE и хотя бы один смерженный PR с описанием
5. Репозиторий публичный, ссылка готова к отправке
